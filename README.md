Мой бот - кнопки для расписания предназначен для учеников, которые хотят узнать расписание на определенный день. Команды: /start, /mon, /tue, /wen, /thu, /fri, /sur; /dev - информация про разработчика, /school - информация про школу, /que - информация про часто задаваемые вопросы.
Я добавил кнопки, чтобы удобнее было выбирать день и предмет, который хочешь посмотреть. Тогда бот выведет полную информацию об уроке и о том кто его ведёт. Теперь он при старте выдает выбор дней недели, которые он знает.
