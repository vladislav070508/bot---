# Telegram Бот: Кнопки для расписания

Этот Telegram бот создан для учеников, которым необходимо быстро получить расписание занятий на определенный день.

## Возможности:

*   **Просмотр расписания:** Получайте детальную информацию об уроках, включая время и учителя, на выбранный день.
*   **Удобные кнопки:** Используйте инлайн-кнопки для простого выбора дня недели и предмета.
*   **Информационные команды:** Узнайте больше о разработчике, школе и часто задаваемых вопросах.

## Команды:

*   `/start`: Запускает бота и предлагает выбрать день недели.
*   `/mon`, `/tue`, `/wed`, `/thu`, `/fri`, `/sat`: Получение расписания на соответствующий день.
*   `/dev`: Информация о разработчике.
*   `/school`: Информация о школе.
*   `/que`: Информация о часто задаваемых вопросах.

При запуске бот автоматически предлагает выбрать доступные дни недели с помощью кнопок.
